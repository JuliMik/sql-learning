# SQL Learning Journey

Practicing SQL as part of my transition into Data Analytics — learning by pairing video tutorials ([Alex The Analyst](https://www.youtube.com/@AlexTheAnalyst)) with hands-on exercises ([SQLZoo](https://sqlzoo.net)).

## Background
Finance & Credit graduate, former software engineer, currently building SQL, Python, and Power BI skills for a Data Analyst role in Ireland.

## Key Concepts Practiced
- Excel: Pivot Tables, VLOOKUP/XLOOKUP, INDEX+MATCH (single & multi-condition), data-driven business insights
- Filtering and sorting (WHERE, ORDER BY, LIKE, wildcards)
- Aggregation (GROUP BY, HAVING, aggregate functions)
- Joining multiple tables (INNER/LEFT/RIGHT JOIN, self-join, 3-table JOIN)
- Subqueries (SELECT within SELECT / WHERE and SELECT clause usage)
- String functions (CONCAT, REPLACE, LENGTH, LEFT)
- Handling data quality edge cases (e.g. distinguishing "credited" vs "actual" values in own-goal scenarios)
